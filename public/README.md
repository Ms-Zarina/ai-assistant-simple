# Опросник базы знаний Simple - Веб-приложение

Веб-приложение для заполнения опросника базы знаний ИИ-консультанта с отправкой ответов в Google Sheets.

## 🚀 Быстрый старт

### Локально

```bash
npm install
npm start
```

Откройте http://localhost:3000

### На Render

1. Залогинься на [render.com](https://render.com)
2. Нажми **New** → **Web Service**
3. Выбери этот репозиторий
4. Установки:
   - **Build command:** `npm install`
   - **Start command:** `npm start`
5. Нажми **Create Web Service**
6. Ссылка готова! 🎉

## 📝 Как использовать

1. Открой форму
2. Заполни опросник
3. Вставь URL Google Apps Script
4. Нажми **"Отправить в Google Sheets"**
