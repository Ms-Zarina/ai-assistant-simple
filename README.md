# ИИ-Ассистент для консультаций (Simple)

Полный пакет для разработки и запуска ИИ-агента, который консультирует клиентов в Instagram Direct и собирает контакты для записи на курсы.

## 📋 Содержание

### 1. **PROMPT_SYSTEM.md** — Инструкция для ИИ-модели
Полная система промптов для Claude/Codex/ChatGPT с:
- Ролью и контекстом агента
- Паттернами поведения (4 фазы консультирования)
- Базой знаний (программы, цены, расписание)
- Тактикой диалога (стиль, примеры ответов)
- Логикой сбора контактов
- Работой с возражениями
- Сценариями (новичок, сомневающийся, медлительный)
- Примерами правильных диалогов

**Как использовать:**
- Скопируй содержимое в System Prompt перед началом диалога с моделью
- Или используй как инструкцию для n8n, Make, или другой платформы автоматизации

---

4 модели ценообразования для клиентов:

| Вариант | Разработка | Сопровождение | Годовая стоимость | Для кого |
|---------|-----------|--------------|------------------|---------|
| **1 - Классический** | $400 | $120-80/мес | ~$2,076 | Бюджетных компаний |
| **2 - Стандартный** | $500 | $140-100/мес | ~$2,376 | Средних компаний |
| **3 - Премиум** | $700 | $160-120/мес | ~$2,260 | Крупных бизнесов |
| **4 - Экспресс** | $450 | $110/мес | ~$1,916 | Срочных проектов |

**Что включено:**
- Разбор каждого варианта подробно
- Сравнительная таблица
- Рекомендации по переговорам
- Ответы на типичные возражения

---

### 3. **CHECKLIST_PREPARATION.md** — Чеклист подготовки
9 разделов с информацией, которую нужно собрать перед разработкой:
- Информация о курсах и ценах
- Примеры реальных диалогов
- Типичные возражения
- Доступы к системам (Instagram, ManyChat, Google Sheets)
- Контакты команды
- Методичка консультирования
- Финансовые параметры

**Сроки подготовки:** 1-2 недели

---

### 4. **FORM_KNOWLEDGE_BASE.html** — Интерактивная форма
HTML форма для сбора и структурирования базы знаний:
- Интерфейс для заполнения вопросов и ответов
- Категоризация по типам вопросов
- Экспорт в JSON/CSV
- Адаптивный дизайн (мобильные + десктоп)

---

### 5. **audit/** — Примеры диалогов
Реальные примеры переписок, которые помогают понять:
- Как консультирует живой менеджер
- На каких этапах берёт контакт
- Какие возражения встречаются чаще всего
- Какие аргументы работают лучше всего

---

### 6. **image/** — Снимки типичных сценариев
Скриншоты реальных диалогов и примеры автоматизаций для визуального понимания процесса.

## 🚀 Как использовать этот репозиторий

### Вариант 1: Вы разработчик (реализуете проект сами)

1. **Прочитайте PROMPT_SYSTEM.md** — поймёте логику агента
2. **Изучите CHECKLIST_PREPARATION.md** — соберите информацию у клиента
3. **Подготовьте базу знаний** — используйте FORM_KNOWLEDGE_BASE.html
4. **Интегрируйте в n8n / Make / другую платформу** — используйте промпт
5. **Тестируйте и дообучайте** — на основе реальных диалогов

### Вариант 2: Вы продаёте проект

1. **Предложите клиенту** один из 4 вариантов из COMMERCIAL_OFFER.md
2. **Отправьте CHECKLIST_PREPARATION.md** — клиент заполняет сам
3. **Используйте PROMPT_SYSTEM.md** при разработке
4. **Обучайте агента** на реальных примерах из audit/

### Вариант 3: Вы ищете вдохновение

- Смотрите примеры диалогов в audit/
- Адаптируйте PROMPT_SYSTEM.md под ваш бизнес
- Используйте FORM_KNOWLEDGE_BASE.html как основу для своей базы знаний

## 📊 Архитектура решения

```
Instagram Direct (источник) 
    ↓
Meta API (получение сообщений)
    ↓
n8n / Make (оркестрация)
    ↓
ИИ-модель (Claude / GPT-4 / другая)
    ↓
Логика консультирования (PROMPT_SYSTEM.md)
    ↓
База знаний (FORM_KNOWLEDGE_BASE.html)
    ↓
Генерация ответа
    ↓
Google Sheets (сохранение контактов)
    ↓
Аналитика (какой источник, когда, результат)
```

## 💡 Ключевые особенности

✅ **Естественный диалог** — агент не выглядит как бот  
✅ **Адаптивность** — учится на реальных примерах  
✅ **Сбор контактов** — фокус на результат, не на спам  
✅ **Аналитика** — видите, что работает, что нет  
✅ **Масштабируемость** — одна система на 10+ менеджеров  
✅ **Ночной режим** — работает 24/7 в пределах политики Meta

## 🎯 Результаты (типичные)

После 2-3 месяцев оптимизации:
- **50-100+ контактов/месяц** (в зависимости от трафика)
- **10-15% конверсия** (из контактов в оплату)
- **50% снижение нагрузки** на менеджеров
- **Улучшение качества** консультаций (агент не устаёт)
