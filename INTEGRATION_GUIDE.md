# ИНСТРУКЦИЯ: Интеграция формы с Google Sheets

## 📋 Шаг 1: Создай Google Sheets таблицу

1. Зайди на [sheets.google.com](https://sheets.google.com)
2. Создай новую таблицу: **Таблица без названия** → переименуй на "Опросник базы знаний"
3. Создай структуру таблицы (первая строка — заголовки):

| Дата | Время | Имя | Email | Вопрос | Категория | Ответ | Приоритет |
|------|-------|------|--------|--------|-----------|--------|-----------|
| (автомат) | (автомат) | (из формы) | (из формы) | (из формы) | (из формы) | (из формы) | (из формы) |

---

## 🔧 Шаг 2: Создай Google Apps Script

1. В Google Sheets нажми **Расширения** → **Apps Script**
2. Удали весь код и вставь это:

```javascript
// Колонки в таблице (соответствуют заголовкам)
const SHEET_NAME = "Sheet1";
const HEADERS = ["Дата", "Время", "Имя", "Email", "Вопрос", "Категория", "Ответ", "Приоритет"];

function doPost(e) {
  try {
    const sheet = SpreadsheetApp.getActiveSheet();
    
    // Получи данные из формы
    const data = JSON.parse(e.postData.contents);
    
    // Подготовь строку для вставки
    const now = new Date();
    const row = [
      now.toLocaleDateString("ru-RU"),           // Дата
      now.toLocaleTimeString("ru-RU"),           // Время
      data.name || "",
      data.email || "",
      data.question || "",
      data.category || "",
      data.answer || "",
      data.priority || ""
    ];
    
    // Вставь строку в таблицу
    sheet.appendRow(row);
    
    // Вернули успешный ответ
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      message: "Данные сохранены!"
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
```

3. Нажми **Развернуть** → **Новое развёртывание**
4. Тип: **Веб-приложение**
5. Выполнять как: **твой Google аккаунт**
6. Кому предоставить доступ: **Любой пользователь в Интернете**
7. Нажми **Развернуть**
8. **Скопируй URL** (вроде `https://script.google.com/macros/s/XXXXX/usercontent`) — это нужен для формы

## 📝 Шаг 3: Обнови форму

Вместо текущей формы используй файл `FORM_WITH_INTEGRATION.html` (я его сейчас создам).

В форме нужно изменить одну строку:

```javascript
const SCRIPT_URL = "https://script.google.com/macros/s/XXXXX/usercontent";
```

Вместо `XXXXX` вставь URL который ты скопировал на шаге 8.

## 🐛 Если что-то не работает

**Ошибка "CORS"?**
- Это нормально для первого запроса
- Попробуй отправить форму еще раз — обычно срабатывает

**Развёртывание не работает?**
- Убедись что выбрал "Веб-приложение"
- Кому предоставить доступ: **Любой пользователь в Интернете**
- Проверь что скопировал правильный URL

**Данные не попадают в таблицу?**
- Открой Apps Script → Выполнение → проверь логи ошибок
- Убедись что имена полей в коде совпадают с именами в форме

---

## 📚 Справка по полям формы

Когда ты заполняешь форму, используй эти названия полей (в коде):

- `name` — имя пользователя
- `email` — email пользователя
- `question` — вопрос клиента
- `category` — категория вопроса
- `answer` — ответ из методички
- `priority` — приоритет (срочный/нормальный)

Все поля опциональные (можно оставить пустыми).
